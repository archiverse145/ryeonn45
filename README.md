## 🚀 Running Locally

You don't need any complex build tools (no `npm install` required). It runs natively in any modern browser!

### Option 1: Python Local Server (Recommended)
```bash
# Clone the repository
git clone https://github.com/archiverse145/ryeonn45.git
cd ryeonn45

# Start local server
python -m http.server 3000
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

### Option 2: Direct Open
Double-click `index.html` in your file explorer to open it in Chrome, Edge, or Safari.

## ☁️ Deploying to Vercel

### Method A: Through Vercel Dashboard (Zero Config)
1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account (`archiverse145`).
2. Click **"Add New..."** → **"Project"**.
3. Import the **`ryeonn45`** repository.
4. Leave all build settings at their defaults (it is a clean static site).
5. Click **Deploy**!
6. Vercel will instantly generate a live URL like `ryeonn45.vercel.app`.

### Method B: Via Vercel CLI
```bash
npm i -g vercel
vercel
```
